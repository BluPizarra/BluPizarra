## About Me

I am a 2nd Year BS Information Technology student based in Metro Manila, Philippines. My work bridges software engineering, relational database management, user-centric interface design, and embedded hardware architectures. I build performant web applications, design relational schemas, explore graph-based routing algorithms, and develop hardware sequencer logic.

- Institution: Asia Pacific College (APC), School of Computing and Information Technologies
- Degree: Bachelor of Science in Information Technology (BS IT)
- Core Focus: Modern Frontend Architecture, Relational Databases (MySQL), Systems Interfacing, Algorithmic Analysis, and UI/UX Design
- Location: Metro Manila, Philippines
